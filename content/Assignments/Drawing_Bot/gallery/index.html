ART 150 / Gallery / Drawing Machines
Intro to New Media Art · Fall 2026

Drawing
Machines

Eighteen vibration-motor robots, each built around a found object and given a set of written instructions. Each drawing was made live in class by following those instructions, in five minutes or less.

Photos marked “Student photo” come from each student's own documentation on Are.na. All other images are stills taken from the class recording of the Drawing Bot Showcase, September 28, 2026. Instructions are transcribed from each student's handwritten card. This class is instructed by Juan Flores.
