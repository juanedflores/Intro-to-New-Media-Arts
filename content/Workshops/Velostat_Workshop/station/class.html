Setting up the Class Sensor Grid

Every student uploads the same class_sensor sketch to their own Nano 33 IoT. Each board sends its Velostat reading over Wi-Fi through the classroom router to this laptop and gets its own tile here, named by the board's ID until the student types their name on it.

Before class

  1. Plug in the router. It doesn't need the internet. Its 2.4 GHz network must be on (the Nano can't use 5 GHz).
  2. Write the router's network name and password on the board: students type them into the two lines at the top of the sketch.

In class

  1. Join this laptop to the router's network.
  2. Double-click start_class_grid.command in the station folder. A Terminal window opens and this page opens in your browser. The Terminal lists each board as it connects. (The first time, macOS may ask whether Python can accept incoming connections: click Allow.)

Students

  1. Wire the sensor: 3.3V → sensor → A0, and a 10kΩ resistor from A0 to GND. Not the power module.
  2. Paste the sketch, type the Wi-Fi name and password, upload.
  3. The Serial Monitor prints the board ID. Find the tile with that ID, click it and type your name. Then squeeze!

Keys

T test mode (hold 1–9, or hold a tile with the mouse) · R recalibrate · F full screen · ? this help

Names are remembered in this browser by board ID, so a student's tile keeps their name next class. Each tile learns its own sensor: the lowest reading is "resting" and the highest is "pressed," so a soft sensor and a stiff one both fill their tile. A board with no sensor reads 0 (the 10kΩ resistor pulls it to ground) and its tile is dimmed.
